仙途 V4 原图像素切图包

范围：21 页，null 个命名矩形切片。
所有切片保留源图原始像素，不缩放、不调色、不重绘。

重要：这是平面设计稿的可见区域裁切，不是分层 PSD 的恢复。切片包含原稿文字、数值以及局部背景。人物、发丝、光效等没有被独立透明抠出；被遮挡区域不存在于输入图中，未伪造补全。请勿将这些切片作为可任意移动的透明组件。当前不适合作为可变数值的最终运行时皮肤。

目录：
每页按 button/icon/item/panel 等分类保存。
remainder.png：在原坐标挖去切片矩形后剩余的画面，不是无 UI 背景。
reassembled.png：从 remainder 加回切片得到的验证图，不是 Unity 运行截图。
manifest.json：坐标、尺寸、源图校验值、各切片校验值。
slice-plan.json：可重复导出的区域定义。
coordinates.csv：可供表格查看的坐标清单。
validation.json：逐切片 PNG 解码校验与整页拼回检查结果。
index.html：逐页预览、范围叠加、原图/拼回图切换、切片列表。

坐标：rect=[x,y,width,height]，左上原点，原生尺寸。unityRect 为左下原点。画布高度 1672；宽度除魂玉 940 外，其余 941。不要把它们当作 1080×1920 的源像素。

拼装：同一页面使用相同等比缩放；remainder 放底层，按原始 x/y 放置全部切片。交叠区域来自同一张源图，像素相同。保留页面边距与纹理，不能做九宫格拉伸或独立重排。

后续独立素材缺口：无字按钮和面板、无数值进度条、透明人物和图标、完整无 UI 场景、被遮挡内容、按下/禁用等未绘制状态。必须另行制作并做视觉对比；不能通过本次矩形切图获取。
