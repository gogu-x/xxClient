# 仙途移动端 UI 页面布局规范

## 设计基准
- 竖屏逻辑画布：1080 × 1920，Canvas Scaler 使用 Scale With Screen Size。
- 背景铺满屏幕；可操作内容遵守系统安全区，避开刘海与手势条。
- 左右边距 40–48；模块间距 24；关联控件间距 12–16。
- 可点击区域最小 88 × 88 逻辑像素；图标可小于触控区域。
- 长列表放在独立滚动区；标题和底部主操作固定。

## 页面骨架
```text
┌────────────────────────────────────┐
│ 返回       页面标题 / 说明      资源 │  顶部：安全区内，约 144 高
├────────────────────────────────────┤
│ 页面摘要、角色状态或关键任务          │  摘要：突出一件最重要的信息
├────────────────────────────────────┤
│ 可滚动内容：列表、装备槽、功能卡片等   │  内容：统一边距和卡片节奏
├────────────────────────────────────┤
│ 次级信息 / 次要操作                  │
├────────────────────────────────────┤
│              主要操作                │  底部：避开手势条，按钮至少 88 高
└────────────────────────────────────┘
```

## 字体与颜色
- 页面标题 40–48；区块标题 26–32；正文 22–26；辅助说明不低于 20。
- 金色用于标题、关键数值和主要操作；玉青用于选中状态；正文用暖白，说明用低饱和浅灰。
- 同层级保持字号、字重和对齐一致；正文优先左对齐。

## 页面族布局
- 大厅保留全景主视觉与固定底部导航；角色信息、快捷入口和当前任务划分清楚。
- 角色选择采用顶部标题、中央角色展示、底部角色选项与确认操作；装备和天赋作为顶部次级入口。
- 装备、背包、任务、宗门等二级页面共用标题区和返回位置；内容按页面性质使用双栏或纵向卡片。
- 天赋、魂玉等养成页保留专属插画与布局，但标题、返回、触控尺寸、留白和文字层级遵守本规范。
- 战斗页将双方状态固定在上方，战场居中，操作固定在下方；返回大厅入口位置稳定。

## 交互要求
- 返回按钮回到进入页面的上一级。
- 选中项有状态反馈；不可用操作显示禁用样式与原因。
- 主按钮承载当前页面最重要的下一步；无后端数据时如实显示同步或未开放状态。
- 页面切换后更新标题、选中状态和数据；重复进入退出不重复绑定事件。
