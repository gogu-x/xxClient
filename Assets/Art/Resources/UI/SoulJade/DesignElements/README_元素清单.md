# 魂玉系统界面拆分素材

共 19 张 PNG：场景、角色、环形机关、中心玉晶、6 枚魂玉图标，以及 9 种独立界面装饰。

## 文件清单
- 01_Scene_Background.png：全屏山门夜景底图
- 02_Hero_Cutout.png：透明底背影角色
- 03_Jade_Ring_Mechanism.png：透明底环形镶玉机关
- 04_Central_Jade_Core.png：透明底中心玉晶
- 05–10：六枚独立魂玉图标（烈阳·破阵、贯日·长弓、玄武·磐石、苍狼·疾步、赤霄·无妄、伏龙·裂空）
- 11–18：装备槽框、详情牌、魂玉陈列台、分类筛选条、底部导航框、资源计数框、标题牌、返回按钮徽章
- 19_SoulJade_Display_Counter.png：效果图魂玉库下方的横向陈列柜台（含台面与雕花前沿）

文字与数值未烘焙到 PNG 中，建议作为独立文字图层排版。
