# UI 贴图美术需求清单

本文档用于记录需要 AI 生图工具（ChatGPT/Midjourney/Stable Diffusion 等）产出的 UI 贴图资源需求。
每一项包含：文件名（生成后请用此文件名保存在本目录下）、用途、尺寸建议、AI 生图提示词、注意事项。

**重要约束：背景图和贴在背景上的 UI 元素（按钮、面板边框、图标等）必须是分开的独立图片，
不能让 AI 把它们画在同一张图里合成好。** 背景图放 `Assets/Art/Backgrounds/`，本文档管的是
贴图型 UI 元素（按钮、面板、图标、边框等独立元素），要求带透明背景（PNG + Alpha 通道），
这样才能在 Unity 里独立控制位置、大小、点击区域，不需要程序再去裁切/抠图。

## 1. 角色页面 - 面板背景框（CharacterPanel_Frame）

- 状态：[x] 已生成并接入代码
- 文件名：`CharacterPanel_Frame.png`
- 用途：角色页面整体的面板装饰边框/底板，铺在标题下方、按钮上方的整个内容区域，
  营造"玉石+金边"的仙侠风格容器感，替换掉当前纯色背景。
- 建议尺寸：1000 x 1600 像素（竖版，覆盖内容区域），透明背景，四周留白边距。
- 提示词（英文，AI生图效果更稳定）：
  ```
  A traditional Chinese xianxia (immortal cultivation) style UI panel frame,
  ornate gold filigree border, dark jade green translucent center panel,
  semi-transparent background so it can overlay a 3D character preview,
  fantasy game UI asset, flat front view, no perspective distortion,
  transparent PNG background, clean vector-like edges, symmetrical design,
  high detail on the gold border ornamentation, no text, no characters inside
  ```
- 注意事项：
  - 中间必须留空/半透明，因为要在上面叠加3D角色预览和文字，不能是实心贴图。
  - 不要在图里画任何文字或角色，纯装饰边框。
  - 透明背景（PNG带Alpha通道），不要白色或纯色底。

## 2. 角色页面 - 返回按钮（Btn_Back）

- 状态：[x] 已生成并接入代码
- 文件名：`Btn_Back.png`
- 用途：角色页面/仙府页面等子页面统一使用的"返回"按钮贴图，替换当前纯色矩形按钮。
- 建议尺寸：300 x 100 像素，透明背景。
- 提示词：
  ```
  A game UI button in traditional Chinese xianxia style, ornate bronze and jade
  texture, rounded rectangle shape, engraved border pattern, empty center area
  for text overlay, front view, flat design, transparent PNG background,
  no text, no characters, game asset icon style, symmetrical
  ```
- 注意事项：
  - 按钮中间留空区域，文字（"返回大厅"）由代码在 Unity 里用 TextMeshPro 叠加显示，不要把文字画进图里。
  - 透明背景。

## 命名与目录约定（供后续新增条目参考）

- 文件名使用 `PascalCase`，模块前缀 + 用途，例如 `CharacterPanel_Frame.png`、`Btn_Back.png`。
- 所有条目必须注明"建议尺寸"和"透明背景"要求（除非明确是需要铺满不透明的背景图，那种放 `Assets/Art/Backgrounds/` 而不是这里）。
- 背景图与其上叠加的 UI 元素永远分开生成，不合并成一张图。
- 生成完成后，把状态改成 `[x] 已生成并接入代码`，并告知我文件已放好，我会去接入 Unity 场景/Prefab。
