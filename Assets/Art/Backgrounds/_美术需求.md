# 背景图美术需求清单

本文档用于记录需要 AI 生图工具产出的**全屏背景类**图片需求（铺满整个屏幕的场景插画）。
每一项包含：文件名、用途、建议尺寸、AI 生图提示词、注意事项。

**重要约束：背景图和贴在背景上的 UI 元素（按钮、面板边框、图标等）必须是分开的独立图片，
不能让 AI 把它们画在同一张图里合成好。** 背景图本身不透明、铺满整个画面即可，UI贴图类
需求见 `Assets/Art/UI/_美术需求.md`。

## 1. 角色页面背景（CharacterPanel_Bg）

- 状态：[x] 已生成并接入代码
- 文件名：`CharacterPanel_Bg.png`
- 用途：角色页面的全屏背景，替换当前纯色占位。风格上要跟大厅背景
  `bg_serverselect_floatingisles.png`（悬浮仙岛、金色夕阳、云雾缭绕）保持同一世界观，
  但场景内容换成室内/洞府感（因为这里是查看/自定义角色的地方，适合一个相对私密、
  聚焦角色本身的场景，比如角色的洞府/静室/藏物阁内部）。
- 建议尺寸：1080 x 1920 像素（竖屏，与大厅背景一致的分辨率）。
- 提示词：
  ```
  A traditional Chinese xianxia (immortal cultivation) style interior scene,
  a cultivator's private chamber / meditation room inside a floating mountain palace,
  warm golden candlelight, jade and bamboo furnishings, large round window showing
  clouds and distant floating islands outside, empty open floor space in the center
  foreground (reserved for character model display), painterly fantasy game background art,
  vertical portrait orientation, no characters, no people, no text, cinematic lighting,
  consistent with a sunset/dusk color palette (warm gold, soft teal, muted jade green)
  ```
- 注意事项：
  - 画面中央/前景区域要相对留空、简洁，因为这个区域会被3D角色模型预览遮挡住，
    背景太复杂会跟角色模型打架。
  - 整张图直接铺满，不透明，不需要 Alpha 通道。
  - 色调要跟大厅背景呼应（暖金色+青绿色），保持视觉世界观统一，不要用差异很大的色系。

## 命名与目录约定

- 文件名使用 `PascalCase`，模块前缀 + 用途，例如 `CharacterPanel_Bg.png`。
- 背景图不透明、铺满整屏，不需要 Alpha 通道（跟 UI 贴图类需求不同）。
- 生成完成后，把状态改成 `[x] 已生成并接入代码`，并告知我文件已放好。
